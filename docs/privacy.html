Privacy Policy

Prefers Checker · Last updated October 22, 2026

The short version

The extension collects no personal data, has no accounts, shows no ads, and includes no analytics. Everything it measures stays on your device. Nothing it sees is sent anywhere, to anyone, ever.

What the extension accesses, and why

Prefers Checker needs a handful of browser permissions to do its one job: measure how the page you are on handles five user-preference media queries. Each permission is used only for that.

activeTab + scripting

Runs the instant scan against the tab you clicked the button on: reads its stylesheets for handling rules, counts running animations, samples text for contrast, weighs loaded resources. Nothing runs on tabs you have not clicked it on.

tabs

Identifies which tab is being scanned so the report attaches to the right page.

storage

Keeps the latest scan result on your device so the popup can show it. Local only; nothing syncs anywhere.

debugger

Powers the deep test. With your button press, it attaches Chrome's debugger protocol to the tab and flips each of the five media features to its requested state via Emulation.setEmulatedMedia, the same mechanism as DevTools' own Rendering panel, re-measures, then clears the emulation and detaches. The debugger is never attached except while a deep test you started is running.

What leaves your device

Nothing. Scan results, page measurements, and verdicts are computed locally and stored only in the browser's on-device storage. The extension makes no network requests of its own: no analytics, no telemetry, no crash reports, no update checks beyond what Chrome itself does for every extension.

This website

This landing page (dominic.balass.one/prefers-browser-extension/) uses Google Analytics to count visits, like the rest of this site family. That is separate from the extension, which has no analytics at all.

Changes

If this policy ever changes, the new version ships with the extension update and the date above moves. The source of truth lives in the open-source repo at github.com/SydBal/prefers-browser-extension; questions and corrections are welcome as issues there.
