Finding the current page...

The deep test attaches the debugger and emulates each preference on this tab, the way the DevTools Rendering panel does. Chrome shows a debugging banner while it runs, and the page is left untouched afterwards.

Honest limits

  • Contrast samples visible text only, flat 4.5:1 threshold, images and gradients skipped.
  • Cross-origin stylesheets cannot be read, so rules inside them are invisible to the scan.
  • If DevTools is open on this tab, the deep test cannot attach.
